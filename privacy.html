Privacy Policy

Google MCP (Local) — last updated 6 November 2026

Overview

Google MCP (Local) is a personal-use application that runs entirely on its owner's computer. It is operated by, and for, a single individual. It has no server, no analytics, no advertising and no third-party integrations other than Google's APIs.

Data accessed

With the owner's explicit consent through Google's OAuth consent screen, the application accesses:

  • Gmail — reading, composing, sending and labelling messages (https://www.googleapis.com/auth/gmail.modify).
  • Google Calendar — reading and managing calendars and events (https://www.googleapis.com/auth/calendar).
  • Google Drive — reading and managing files (https://www.googleapis.com/auth/drive).
  • Account email address — to label which account is connected (userinfo.email, openid).

How data is used

Data is retrieved from Google only when the owner asks the AI assistant to perform a task, and is used solely to carry out that task. The application does not use Google user data for any other purpose.

Storage

OAuth refresh and access tokens are stored in a local configuration directory on the owner's computer with owner-only file permissions. Email, calendar and file contents are not persisted by the application; they are passed to the AI assistant for the duration of the request only.

Sharing

Google user data is never sold, shared with, or transferred to any third party. The only external service contacted is Google's own API endpoints.

Limited Use disclosure

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions or by deleting the locally stored tokens.

Contact

Questions about this policy can be sent to the support email shown on the Google consent screen.
